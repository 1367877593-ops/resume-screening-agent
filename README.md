# Recruit — 智能简历解析与试题生成引擎

一个 AI Agent 系统：输入 JD 与若干份简历（PDF/Word），输出可审计的匹配评分、
针对性面试题目与追问，并由独立的 Checker Agent 校验后闭环修订。

> 当前状态：架构设计已完成，开发中。完整设计见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 核心能力

| 模块 | 能力 |
|---|---|
| 结构化提取 | 解析简历并抽取关键信息，每个字段携带原文出处（`source_span`） |
| 匹配打分 | JD 拆解为加权要求项，逐条判定并引用证据，分数由代码加权得出 |
| 试题生成 | 生成 ≥10 道面试题，含考察点、难度、分档评分标准 |
| 追问模拟 | 识别简历模糊点，生成 3–5 个针对性追问 |
| Checker Agent | 静态规则校验 + 语义校验 + 三人格模拟压测，闭环修订 |

## 设计亮点

**证据链驱动**  
每一条结论都必须挂原文出处。说不出出处的结论由 Checker 直接判为不通过，
用确定性的字符串匹配拦截幻觉与归因错误。

**三人格模拟验题**  
题目生成后，由「理想专家 / 背题党 / 简历人格」三个 Agent 在信息隔离条件下作答，
盲评打分后三分对照，把「题目质量」从主观感受变成可测量信号。
专家答不出 → 题目有问题；背题党也能答 → 题目无区分度。

**反思飞轮**  
Checker 每次发现的问题沉淀为经验库，下次生成时按场景检索注入，形成越用越准的闭环。
